# ShipMS 🚢

A Full Stack Ship Management System built using React, Node.js, Express.js and MongoDB.

## Features

- User Authentication (Login/Register)
- Fleet Management CRUD
- Captains Management CRUD
- Dashboard Analytics
- Search Ships
- Captain AI Assistant
- Responsive UI

## Tech Stack

### Frontend
- React.js
- Tailwind CSS
- React Router DOM
- Recharts
- Three.js

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication

## Installation

### Frontend

```bash
cd Frontend
npm install
